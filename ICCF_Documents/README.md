# ICCF Documents & University Reference Materials

This directory stores project documentation, architectural blueprints, system manuals, academic department rosters, and assessment questionnaires for the **Manav Rachna ICCF (Industry Curriculum & Competency Framework) / SkillCert Portal**.

---

## 📁 Directory Contents

| File / Folder | Format | Description |
| :--- | :--- | :--- |
| `COMPLETE_DOCUMENTATION.md` | Markdown | Exhaustive end-to-end documentation covering architecture, authentication models, role permission matrices, backend routes, and security hardening recommendations. |
| `DOCUMENTATION_INDEX.md` | Markdown | Navigational index to all chapters and sections in the system documentation. |
| `Skill Framework Questionnaire Master Copy.docx` | MS Word (`.docx`) | Master copy of the assessment questions and competency framework questionnaire. |
| `MRU_DEPTWISE-INFO_26/` | Folder / Excel | University departmental details and directory (`MRU TELEPHONE DIRECTORY 24.03.2026.xlsx`). |

---

## 📖 Key Documentation Highlights

- **Security & Access Control**: Explains the 30-second rotating JWT policy, HttpOnly refresh cookie mechanism, and RBAC enforcement.
- **Departmental Hierarchy**: Maps out faculty structures, Dean and HOD authorization rules, and student grouping per department.
- **Competency Mapping**: Links university curricula to industrial competency levels (Foundational, Intermediate, Advanced).
